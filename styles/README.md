# HTML & CSS Project

This repository contains the HTML and CSS files for the project.

## 🔗 HTML & CSS File Matching

Each HTML file has a corresponding CSS file inside the `styles` folder.

The **HTML and CSS files use the same name** so that the corresponding stylesheet can be easily found.

|HTML File|Corresponding CSS File|
|---|---|
|`ex12.12.html`|`styles/ex12.12.css`|

### Example

```
index.html
styles/index.css
```
